# 🌍 TravelWorld

**TravelWorld** is a modern and responsive travel destination website designed to help users discover and explore beautiful destinations around the world.

## ✨ Features

* 🏠 Modern and responsive landing page
* 🔎 Destination search and filtering
* 🗂️ Travel categories
* ⭐ Featured destinations
* 📍 Destination details modal
* 📱 Mobile-friendly navigation
* ✨ Smooth scroll animations
* ⬆️ Back-to-top functionality
* 🎉 Interactive booking request
* ⏳ Website preloader

## 🛠️ Technologies

* **HTML5** – Website structure
* **CSS3** – Styling, animations & responsive design
* **JavaScript** – Interactive functionality
* **Google Fonts** – Typography
* **Font Awesome** – Icons

## 🚀 Getting Started

1. Clone or download the repository.
2. Open the project in **VS Code**.
3. Open `index.html` with **Live Server**.
4. Explore the TravelWorld website.

## 📱 Responsive Design

TravelWorld is optimized for **desktop, tablet, and mobile devices**, with responsive layouts and a mobile hamburger menu.
